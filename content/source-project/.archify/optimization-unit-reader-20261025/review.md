# 單元總結閱讀優化驗證

完成日期：2026-10-25。範圍為 23 個考科單元的 Archify 教材頁閱讀介面。

- 清晰閱讀會量測 SVG 文字後調整倍率；390px 與 1440px 各測 23 章，主節點文字最小 14.04px。全圖可回到完整關聯總覽。
- 文字導讀預設 18px，概念、關係與提示都由已審查的候選來源產生；可前後閱讀、沿關係跳轉並定位回圖。
- 已驗證即時比例、縮放上下限、閱讀偏好、鍵盤頁籤、全螢幕、深色主題、觸控拖曳及快速切換章節。
- HTTP 失敗、控制器錯誤與 20 秒逾時皆可重試；失敗時文字導讀仍可使用，重試也可由有效的預快取完成。
- 53 個介面案例加 1 個實際離線案例，共 54 項通過，無未處理 JavaScript 錯誤。
