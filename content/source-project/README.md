## 鑑定期程與合格標準

* **評鑑科目**：
  * 科目 1：生產與作業管理基礎（學科，單選 50 題，75 分鐘）
  * 科目 2：智慧製造生產線管理基礎（學科，單選 50 題，75 分鐘）
* **及格門檻**：
  * 雙科同時報考：兩科平均成績 $\ge 70$ 分，且任一單科成績不得低於 $60$ 分。
  * 單科合格成績保留 3 年，單科及格成績標準為 $70$ 分。

## 📱 PWA 網頁應用程式 (Progressive Web App)

本專案已完全比照 `pwa_QuizQuiz` 規格建置現代化、輕量級且支援離線快取之 PWA 閱讀與備考系統。

### 🚀 常用指令

```bash
# 1. 開啟本機開發預覽伺服器
npm run dev

# 2. 自動同步並轉譯最新 Markdown 筆記為單元教材
npm run sync:materials

# 3. 靜態站點打包 (輸出至 dist/ 目錄，可直接部署至 GitHub Pages)
npm run build

# 4. 預覽打包產物
npm run preview
```

### ✨ 核心功能
1. **KaTeX 向量數學公式渲染**：完整支援 $C_{pk}$、ST、EOQ、OEE 等公式即時清晰渲染。
2. **Design Tokens 視覺系統**：支援白日淺色模式與深色夜間模式無縫切換、字體大小多段縮放。
3. **Service Worker 離線快取**：具備完整 PWA Manifest，可在手機或桌面端直接點擊「加入主畫面 / 安裝應用程式」完全離線閱讀。
