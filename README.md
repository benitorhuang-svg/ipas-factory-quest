## 專案亮點

- **全科目十二單元完整對齊**：
  - **科目一：生產與作業管理基礎**（L111～L116，共 6 單元、242 道不同內容）
  - **科目二：智慧製造生產線管理基礎**（L121～L126，共 6 單元、174 道不同內容）
- **416 道不同內容練習題**：保留 476 筆原始資料與舊進度；新任務依內容去重，每單元 22～42 道不同內容。相同內容不重複計算新 XP。
- **28 篇完整教材與 3D 渲染圖解**：
  - 涵蓋初級兩科 12 章、科目三術科實作 2 篇、中級智慧製造 9 章及考綱對照實戰 5 篇。
  - 備考寶典以分類目錄為入口，26 篇講義支援關鍵字搜尋與科目篩選；公式及避坑兩篇附錄整合至專屬分頁，保留全部教材。
  - 寬螢幕提供固定段落索引與目前段落標示，小螢幕改為收合；同一分頁重開講義可接續上次閱讀位置。
- **複習圖鑑（依單元整合架構）**：
  - 側邊欄為單一主入口；頁面標題與「全部圖鑑／科目一／科目二／全廠總覽」統一置於頂欄，內容區直接呈現圖鑑卡片。
  - 每個單元同時收錄：**高解析架構分解圖**、**3D 立體圖解**、**全螢幕互動架構閱讀器**、**精讀講義**與**單元闖關**捷徑。
  - 頂部設有【全廠宏觀與跨層級全景】（ISA-95 五層工廠全景互動模型、職能 3D 分解爆炸圖、全科分解圖、23 單元總覽閱讀器）。
- **備考寶典（四大核心學習模組）**：
  - **精讀講義**：按初級兩科、術科、中級與延伸閱讀分組；桌機雙欄目錄、手機單欄閱讀。
  - **專有名詞辭典**：165 條專業名詞以**行列式（表格 Table：英文簡寫／全寫／中文）**呈現，依**英文字母 A～Z 順序**排列，支援關鍵字即時模糊過濾搜尋。
  - **公式手冊**：統一使用完整公式教材，收錄標準工時、線平衡、EOQ/EPQ、安全庫存、OEE、可靠度與製程能力七類題型及計算示例。
  - **易錯觀念**：十項完整陷阱辨析，另保留 SPC、MRP 與通訊協定的補充；舊附錄連結自動導向對應分頁。
- **考前模擬與歷屆試題下載**：
  - **全真模擬考**：科目一與科目二（各 50 題 / 75 分鐘），均勻抽題、離開頁面計時不中斷、時間到自動交卷。
  - **官方試題與簡章 PDF 下載**：收錄 115 年第一次初級／中級官方公告試題、術科樣題標準與鑑定簡章（含歷史版本共 9 份 PDF），支援線上直接開啟與下載。
- **純靜態零依賴與 PWA 離線支援**：
  - 純 HTML、CSS、Vanilla JavaScript，本機直接開啟或靜態託管隨處可跑。
  - 支援 PWA 漸進式網頁應用安裝，外殼、章節文字與本機 KaTeX／完整字型列入預快取；圖片、互動頁與 Mermaid 按需快取，亦可在成長紀錄下載完整章節。更新等待舊分頁結束。

## 介面與閱讀流程

- 頁面標題與分區集中於頂欄；首頁突出一個建議任務，通關、經驗與錯題以簡潔數據列呈現。
- 圖鑑以單元為主，圖片直接開啟放大閱讀；全廠總覽在「全部圖鑑」中收合，也可從頂欄直接進入。
- 講義目錄返回後保留搜尋、分類與捲動位置；錯題依單元收合，作答報告可只顯示答錯題目。
- 圖解與公式引擎按需載入，完整公式排版使用站內資源；圖片載入失敗會顯示提示，放大視窗可重試。
- 每次修改執行程式或樣式後請執行 `npm run build`，依資產內容重建快取版本，避免新舊模組混用。
- 執行 `npm run lint` 與 `npm test` 可檢查導航、作答、彈窗焦點及快取清單。這些檢查不代表已完成瀏覽器視覺或離線驗收，詳見 [介面驗收紀錄](docs/UI_REDESIGN.md)。

直接雙擊開啟 `dist/index.html` 即可使用。

若要使用本機網頁伺服器：

```sh
python -m http.server 8000 --directory dist
```

## 題庫與遊戲機制

- **單元 10 題闖關**：從各單元題庫中隨機抽選 10 題（概念辨識、現場決策、計算題），整批交卷後查看完整逐題解析。通關門檻 80 分，首次通關頒發部門專屬成就徽章與 +50 XP。
- **5 題快速回想**：隨機抽 5 題快速熱身。
- **錯題返修中心**：錯題優先、到期題其次；再次答對移出今日清單，三天後再安排回想。
- **考前全真模擬考**：
  - 科目一（50 題 / 75 分鐘）：均勻涵蓋 L111～L116 六大單元。
  - 科目二（50 題 / 75 分鐘）：均勻涵蓋 L121～L126 六大單元。
  - 離開頁面計時不中斷，倒數 5 分鐘警示，時間到自動交卷。
- **進度備份**：學習歷程儲存於瀏覽器 LocalStorage，支援 JSON 一鍵匯出與跨裝置匯入。

## 執行檢查

完整建置與自動檢查：

```sh
npm ci
npm run build
npm run lint
npm test
```

來源整合與圖解修正紀錄見 [資料整合與圖解驗證](docs/source-integration.md)。
`content/source-integration.json` 列出 891 個來源檔案的去向與 SHA-256；
來源專案獨有的程式、設定、設計稿與歷次輸出保存在 `content/source-project/`。
整合工具不覆蓋本專案不同版本，並排除 `.git`、`node_modules` 及可重建的來源 `dist`。
來源資料夾仍存在時，可執行 `npm run integrate:source` 重新補入資料。

圖解測試使用隨站附帶的 Mermaid 解析器檢查全部 60 張圖；DOM 測試涵蓋講義路由、
放大閱讀、渲染排程與失敗提示。這些測試不包含實際瀏覽器排版與離線操作驗證。

已安裝 Node.js 時，在專案根目錄執行：

```sh
node tests/validate.cjs
```

測試將全面驗證：
1. 題庫 476 題總數與 ID 唯一性。
2. 12 個單元完整性與對應 `dist/assets/*.png` 高解析圖存在性。
3. 題目題幹、選項、答案合法性與數值輸入驗證。
4. 模擬考 50 題兩科均勻抽題與計分冪等性。
5. 錯題返修流程、暫存恢復與連勝天數計算。

## 深度優化與瀏覽器驗證

- 匯入防護、內容去重、到期複習、單一寫入分頁、章節離線下載與效能量測見 [深度優化紀錄](docs/OPTIMIZATION.md)。
- `npm run build` 先建立按章教材、WebP 預覽與離線清單，再更新快取版本；請勿直接使用舊的 rebuild-clean 等遷移腳本作為日常建置。
- `npx playwright install chromium webkit` 後執行 `npm run test:browser`；SW 的原生離線與更新驗證限 Chromium，其餘流程也涵蓋 WebKit。
- `npm run report:content` 更新 [題庫覆蓋表](docs/QUESTION_COVERAGE.md)。416 題均有內容指紋與審查台帳，人工答案／細項能力點審核仍為待處理。
- 支援 Web Locks 的瀏覽器同時只允許一個分頁修改進度；其他分頁可閱讀與匯出，原分頁關閉後可重新取得作答權。
