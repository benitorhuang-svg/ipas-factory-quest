# 智造闖關 Factory Quest — iPAS 智慧生產工程師全方位備考平台

依據經濟部產業人才能力鑑定標準（職能基準代碼：**MPM3117-001v3**）與 115 年度最新鑑定規範建置。結合情境闖關、歷屆題庫、高解析分解結構圖、名詞辭典速查、核心公式彙整與完整教材筆記。

---

## 專案亮點

- **全科目十二單元完整對齊**：
  - **科目一：生產與作業管理基礎**（L111～L116，共 6 單元、272 題）
  - **科目二：智慧製造生產線管理基礎**（L121～L126，共 6 單元、204 題）
- **476 題巨量題庫**：包含 160 題情境決策與計算題 + 316 題分章對照實戰練習題，每單元 28～50 題。
- **備考寶典**：
  - **專有名詞辭典**：165 條中英對照與英文全稱，支援即時關鍵字過濾搜尋。
  - **核心計算題公式速查**：標準工時 (ST)、EOQ/EPQ、線平衡率、OEE (A×P×Q)、Cp/Cpk 等 8 大題型公式推導與口訣。
  - **常考陷阱與干擾項辨析**：整理歷屆考生最易失分的 10 大出題盲點。
  - **歷屆試題與官方簡章 PDF**：收錄 115 年第一次初級／中級公告試題、術科樣題標準與鑑定簡章。
- **14 張高解析分解結構圖**：12 個單元章節結構圖 + 2 大科目全景圖，支援在線放大與原尺寸分頁閱讀。
- **純靜態零依賴**：純 HTML、CSS、Vanilla JavaScript，無需任何前端打包或 npm 建置工具，本機直接開啟或靜態主機隨處可跑。

## 本機開啟

直接雙擊開啟 `dist/index.html` 即可使用。

若要使用本機網頁伺服器：

```sh
python -m http.server 8000 --directory dist
```

再用瀏覽器開啟 [http://localhost:8000/](http://localhost:8000/) 。

## 題庫與遊戲機制

- **單元 10 題闖關**：從各單元題庫中隨機抽選 10 題（概念辨識、現場決策、計算題），整批交卷後查看完整逐題解析。通關門檻 80 分，首次通關頒發部門專屬成就徽章與 +50 XP。
- **5 題快速回想**：隨機抽 5 題快速熱身。
- **錯題返修中心**：所有曾答錯的題目自動集中列管，再次答對即可修復移出待辦。
- **考前全真模擬考**：
  - 科目一（50 題 / 75 分鐘）：均勻涵蓋 L111～L116 六大單元。
  - 科目二（50 題 / 75 分鐘）：均勻涵蓋 L121～L126 六大單元。
  - 離開頁面計時不中斷，倒數 5 分鐘警示，時間到自動交卷。
- **進度備份**：學習歷程儲存於瀏覽器 LocalStorage，支援 JSON 一鍵匯出與跨裝置匯入。

## 執行檢查

已安裝 Node.js 時，在專案根目錄執行：

```sh
node tests/validate.cjs
```

測試將全面驗證：
1. 題庫 476 題總數與 ID 唯一性。
2. 12 個單元完整性與對應 `dist/assets/*.png` 高解析圖存在性。
3. 題目題幹、選項、答案合法性與數值輸入驗證。
4. 模擬考 50 題兩科均勻抽題與計分冪等性。
5. 錯題返修流程、暫存恢復與連勝天數計算。
