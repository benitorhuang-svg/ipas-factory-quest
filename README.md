# 智造闖關 Factory Quest — iPAS 智慧生產工程師全方位備考平台

> 依據經濟部產業人才能力鑑定標準（職能基準代碼：**MPM3117-001v3**）與 115 年度最新鑑定規範建置。結合情境闖關、歷屆題庫、單元整合圖鑑、名詞辭典速查、核心公式手冊、考題陷阱避坑與 28 篇全章節深度講義。

## 專案亮點

- **全科目十二單元完整對齊**：
  - **科目一：生產與作業管理基礎**（L111～L116，共 6 單元、272 題）
  - **科目二：智慧製造生產線管理基礎**（L121～L126，共 6 單元、204 題）
- **476 題巨量題庫**：包含 160 題情境決策與計算題 + 316 題分章對照實戰練習題，每單元 28～50 題。
- **28 篇單元精讀講義與 3D 渲染圖解**：
  - 涵蓋初級兩科 12 章、科目三術科實作 2 篇、中級智慧製造 9 章及考綱對照實戰 5 篇。
  - 頂部導航支援快速切換單元章節、前後篇翻頁及「28 單元目錄速查抽屜」。
- **複習圖鑑（依單元整合架構）**：
  - 側邊欄簡化為單一主入口，進入後以**學習單元（L111～L126）**為核心整合成全景卡片。
  - 每個單元同時收錄：**高解析架構分解圖**、**3D 立體圖解**、**全螢幕互動架構閱讀器**、**精讀講義**與**單元闖關**捷徑。
  - 頂部設有【全廠宏觀與跨層級全景】（ISA-95 五層工廠全景互動模型、職能 3D 分解爆炸圖、全科分解圖、23 單元總覽閱讀器）。
- **備考寶典（四大核心學習模組）**：
  - **專有名詞辭典**：165 條專業名詞以**行列式（表格 Table：英文簡寫／全寫／中文）**呈現，依**英文字母 A～Z 順序**排列，支援關鍵字即時模糊過濾搜尋。
  - **核心計算題公式速查**：標準工時 (ST)、EOQ/EPQ、線平衡率、OEE (A×P×Q)、Cp/Cpk 等 8 大題型公式推導與記憶口訣。
  - **常考避坑盲點**：精析外加法/內含法、SPC 管制界限 vs 規格界限、MRP 淨需求、過殺/漏判等 10 大經典誘答陷阱。
- **考前模擬與歷屆試題下載**：
  - **全真模擬考**：科目一與科目二（各 50 題 / 75 分鐘），均勻抽題、離開頁面計時不中斷、時間到自動交卷。
  - **官方試題與簡章 PDF 下載**：收錄 115 年第一次初級／中級官方公告試題、術科樣題標準與鑑定簡章（共 7 份 PDF），支援線上直接開啟與離線下載。
- **純靜態零依賴與 PWA 離線支援**：
  - 純 HTML、CSS、Vanilla JavaScript，本機直接開啟或靜態託管隨處可跑。
  - 支援 PWA 漸進式網頁應用安裝，內建離線 KaTeX 數學公式與離線 Mermaid 架構圖渲染引擎。

## 本機開啟

直接雙擊開啟 `dist/index.html` 即可使用。

若要使用本機網頁伺服器：

```sh
python -m http.server 8000 --directory dist
```

再用瀏覽器開啟 [http://localhost:8000/](http://localhost:8000/) 。

## 題庫與遊戲機制

- **單元 10 題闖關**：從各單元題庫中隨機抽選 10 題（概念辨識、現場決策、計算題），整批交卷後查看完整逐題解析。通關門檻 80 分，首次通關頒發部門專屬成就徽章與 +50 XP。
- **5 題快速回想**：隨機抽 5 題快速熱身。
- **錯題返修中心**：所有曾答錯的題目自動集中列管，再次答對即可修復移出待辦。
- **考前全真模擬考**：
  - 科目一（50 題 / 75 分鐘）：均勻涵蓋 L111～L116 六大單元。
  - 科目二（50 題 / 75 分鐘）：均勻涵蓋 L121～L126 六大單元。
  - 離開頁面計時不中斷，倒數 5 分鐘警示，時間到自動交卷。
- **進度備份**：學習歷程儲存於瀏覽器 LocalStorage，支援 JSON 一鍵匯出與跨裝置匯入。

## 執行檢查

已安裝 Node.js 時，在專案根目錄執行：

```sh
node tests/validate.cjs
```

測試將全面驗證：
1. 題庫 476 題總數與 ID 唯一性。
2. 12 個單元完整性與對應 `dist/assets/*.png` 高解析圖存在性。
3. 題目題幹、選項、答案合法性與數值輸入驗證。
4. 模擬考 50 題兩科均勻抽題與計分冪等性。
5. 錯題返修流程、暫存恢復與連勝天數計算。
