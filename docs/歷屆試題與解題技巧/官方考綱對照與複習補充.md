# 官方考綱對照與複習補充

115 年初級智慧生產工程師的兩個學科皆採 **75 分鐘、單選題、電腦化測驗（Computer-Based Test, CBT）**。考科一聚焦生產管理、物料管理、工業工程與品質管制；考科二聚焦智動化設備、智慧製造與智慧化現場管理。

## 1. 考科一：從計畫到現場改善

* **計畫與流程：** 銷售與營運規劃（Sales and Operations Planning, S&OP）、主生產排程（Master Production Schedule, MPS）、製程途程（Routing）、瓶頸與生產前置時間（Lead Time, LT）要能用於判斷交期與產能負荷。
* **物料管理：** 區分需求預測、安全庫存（Safety Stock, SS）、物料清單（Bill of Materials, BOM）與物料需求規劃（Material Requirements Planning, MRP）的角色；安全庫存是吸收變異，不是消除預測需求；ABC 存貨分類法落實重點管制。
* **IE、品質與精實：** 運用時間研究與動素分析消除浪費；製程能力指標（Cp / Cpk）要分清「變異寬度」與「是否置中」；防呆法（Poka-Yoke）源頭預防優先於事後全檢。

## 2. 考科二：從設備資料到現場執行

* **架構分層：** 企業控制系統整合標準（Enterprise-Control System Integration, ISA-95）的 Level 3 製造營運管理，將企業規劃與現場設備控制緊密連結。
* **通訊連線：** 理解設備資料如何經由工業物聯網（Industrial Internet of Things, IIoT）通訊、邊緣運算或物聯網平台流動；Modbus 負責底層設備暫存器輪詢，OPC UA 支援跨平台物件導向資訊模型，MQTT 則是輕量發布／訂閱架構。
* **現場智動化應用：** 自動光學檢測（Automated Optical Inspection, AOI）要嚴密防範漏檢風險；網宇實體系統（Cyber-Physical System, CPS）與數位雙生（Digital Twin, DT）強調虛實資料雙向閉迴路回饋；製造執行系統（Manufacturing Execution System, MES）即時追蹤工單生命週期、在製品（Work in Process, WIP）與生產履歷。

## 3. 題目判讀四步驟

1. 先圈出題幹要解決的核心問題：交期、庫存、品質、設備故障或系統整合。
2. 辨識決策層級：企業資源規劃層、製造營運執行層、設備控制層或底層感測資料層。
3. 排除把「工具名稱」誤當「改善目的」的選項，例如以事後全檢取代防錯設計。
4. 用題目給定之已知條件驗證答案；沒有提供特定計算參數時，不自行假設未出現之數值。
