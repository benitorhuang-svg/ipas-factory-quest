## 第二輪深度優化

- 長篇講義在 1360 px 以上使用固定段落索引，小螢幕維持收合；目前閱讀段落以 `aria-current` 標示。同一瀏覽器分頁可接續閱讀位置，定位以段落與相對位移儲存，圖解／公式載入後可重新對齊；使用者捲動後停止自動還原。
- KaTeX 維持原本的 0.16.9 版本，JS、CSS 與全部字型改為站內資源。來源為 npm 官方 registry，已核對套件 SHA-512 integrity，保留 MIT 授權與 63 個資產的 SHA-256 清單於 `dist/assets/vendor/katex/manifest.json`。
- 完整引擎會等待 CSS 就緒後升級基本公式呈現；樣式失敗可重試。28 篇教材共 610 個公式均以實際 KaTeX 渲染，兩個攝氏度符號補上明確的空基底，消除原本的解析錯誤。
- 圖片載入失敗會顯示文字提示，放大視窗出現重試按鈕；恢復連線時會重試目前頁面失敗的圖片。
- `npm run build` 依外殼、公式字型與 SW 內容產生快取版本，主 SW 同時更新版本註記。安裝版本內的外殼固定使用同一份快取，避免背景更新造成模組混用。
- 圖片、PDF 與互動頁使用獨立的內容快取；更新時遷移舊快取，容量不足時保留舊內容，避免遺失。快取寫入納入事件生命週期；跨來源、其他安裝路徑、非 GET 與 Range 請求交回瀏覽器。
- 目前預快取 103 個站內資產。未快取且離線的互動頁／圖片等回傳明確的 503 回應與說明，不會回傳 `undefined` 或把主站首頁當作互動頁。這些替代回應不會存成真實資產。

## 驗證方式與邊界

- `npm run build`：依保留的教材來源產生 28 篇教材與 476 題，並重建 `precache.js` 及 SW 版本註記。
- `npm run lint:fix`、`npm run lint`：新拆分的執行模組納入 lint；瀏覽器模組也檢查未定義名稱。
- `npm test`：包含題庫／計分、891 個來源檔案雜湊、60 張 Mermaid 語法、26 篇閱讀頁及 2 個附錄轉向、圖鑑分類、目錄條件與位置還原、彈窗焦點、闖關／解析／錯題複習、兩科模考到時交卷、取消重設、按需載入與快取契約。
- 行為測試在 jsdom 執行，dialog 只模擬開啟／關閉契約；不代表原生焦點鎖定或瀏覽器排版已驗證。
- 快取測試模擬 SW 的 install／activate／fetch 事件，涵蓋內容遷移、寫入壽命、離線回應、HTTP 錯誤、容量不足與 Range；不代表實際瀏覽器已完成離線安裝。公式與字型已納入外殼快取，圖片與互動 HTML 延續按需快取。
- 閱讀定位測試使用模擬元素座標，涵蓋內容上移／下移、手動捲動取消還原、同分頁接續與監聽器清理；不代表真實瀏覽器尺寸與字型載入後的視覺驗收。
