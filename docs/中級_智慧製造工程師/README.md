# 中級：智慧製造工程師能力鑑定（L2）

依據官方簡章，中級考試包含兩個科目，各考 **90 分鐘、100 題單選題、電腦測驗（CBT）**，兩科同日在台北、台中、虎尾、高雄舉行。

## 考試架構

| 科目 | 考試時間 | 內容 |
| :--- | :--- | :--- |
| **L21 智慧製造生產與作業管理之實務應用** | 13:30–15:00（90 分鐘） | 精實管理、智慧工廠、MES 整合、生產排程優化、品質大數據分析 |
| **L22 智慧製造之設備與製程管理之實務應用** | 15:30–17:00（90 分鐘） | IoT 原理、CPS、設備維護、感測器/機器視覺/機器人工業應用、通訊建構 |

## 授證資格

同時報考並且**平均達 70 分，且每科不低於 60 分**；或分次報考各科均達 70 分。

## 中級 vs. 初級差異

| 維度 | 初級 | 中級 |
| :--- | :--- | :--- |
| 知識深度 | 瞭解概念、基本辨識 | 能應用整合、判斷優化方向 |
| 計算題類型 | 標準工時、MRP 淨需求、看板數量 | 生產排程優化（CR/SPT）、線平衡改善、製程能力 Cpk 進階、OEE 六大損失拆解 |
| 系統整合 | MES 單模組功能 | MES↔ERP 全廠資訊流、MES↔設備整合、大數據應用 |
| 設備知識 | 基本操作與保養 | 維護策略選擇（PM/CBM/PdM）、設備介面規格、通訊建構 |

## 詳細單元的深度研讀任務

05–13 每章均有「深度研讀」整合案例及兩題進階練習解析。中級的重點是條件改變後能重新做決策：先定義目標與系統邊界，再推導數值、檢查限制，最後說明應如何驗證方案。案例中的投資、品質與控制門檻均須依其原創假設判讀。

| 詳細單元 | 深度主題 | 建議自行完成的產出 |

| [05 生產與精實](./05_生產管理實務與精實管理.md) | 混線 MPS／CRP、物料與 ATP | 原訂單與急單的資源負荷表、跨週可承諾交付方案 |
