# 逐題深化審查：2026-11-07

本輪涵蓋 **616 道不同題目**：416 道原創練習題（其中 396 道可供模擬考、20 道數值題）及四科 200 道公告試題。476 筆練習題來源及既有別名均保留。

審查者為 Codex，性質是代理內容審查，並非官方認證或獨立命題專家簽核。審查完成包含明確記錄歧義，不代表把有歧義的題目宣告為無條件正確。

- 公告檢核以「原解析 SHA-256＋原始 PDF SHA-256＋手寫檢核 SHA-256＋頁碼」綁定；漏題、答案不符或任一內容改動未複核即拒絕建置。

- 上一版與最初版的作答、選項次序、歷史報告、計分容差及已取得 XP 均保留。上一版 88.88 曾被接受的報告與草稿不會在本輪被重新判錯；新作答套新取位要求。
- 原始整合來源及 `content/question-legacy.json` 未改寫。來源狀態台帳仍有 **36 筆 pending**，代表待獨立人工複核；本輪代理審查不把它們自動標為專家簽核，也不重寫既有 reviewer 身分。
