## 維護方式

- 教材文字是內容依據；修訂教材後，重新檢視該單元圖中的節點、箭頭與提示卡。
- JSON 編輯來源與 Archify 收據位於 .archify/architecture-unit-summaries-20261024-120610/各單元目錄。每張應通過 finalize，並將已驗證 HTML 複製至 public/assets/interactive-diagrams/unit-summaries/對應代碼.html。
- 完成內容審查與重新產圖後，以 node .archify/architecture-unit-summaries-20261024-120610/build-index.mjs 更新索引與來源雜湊清單。該命令只產生索引，不更新圖中知識。
- 執行 npm run check:unit-summaries 檢查 23 單元覆蓋、教材來源雜湊、公開 HTML 與 Archify 收據的一致性，再執行 npm run typecheck 與 npm run build。
- 頁首入口由 src/components/UnitSummary.ts 共用提供；教材同步仍可照原流程執行。

## 載入與離線

圖表進入可視範圍附近時才建立內容載入；iframe 使用獨立 sandbox，並提供完整圖的新頁面入口。正式打包時互動 HTML 會納入既有 PWA 預快取。

## 互動閱讀

- 頁首提供「全圖」與「清晰閱讀」；清晰閱讀以節點標題約 14px 為縮放目標，並顯示即時比例。可放大、縮小、拖曳及全螢幕閱讀，選擇的模式會沿用到其他單元。
- 「文字導讀」以 18px 大字呈現概念、上下游關係與複習提示；可逐點閱讀，再定位回互動圖。大字偏好會保存於本機。
- 導讀由已審查的 candidate.json 產生；更新圖表後執行 `npm run sync:unit-summary-readers`。`check:unit-summaries` 與建置前檢查會防止導讀和圖表來源不一致。
- 載入有 20 秒上限，失敗時可重試；文字導讀可獨立使用。記憶體最多保留四份圖表文件，切換單元時會清理接收器與未完成請求。
- 正式版會預快取 23 份 `.reader.json`，使離線教材同時提供互動圖與文字導讀。
- 建置後會核對所有圖表與導讀的快取內容指紋；首次安裝的 Service Worker 會立即接管，避免沿用無版本的教材快取。
