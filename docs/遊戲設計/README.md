# 智慧工廠：接單挑戰 — 遊戲設計總覽

設計版本：1.1｜日期：2026-09-25｜狀態：108 關設計完成，尚未實作遊戲。

本設計採「卡牌決策＋回合制工廠／資料流模擬」。玩家在有限資源下接單、規劃、製造、檢驗與改善，從可觀察的結果理解 iPAS 智慧生產工程師教材。塔防的波次感用於訂單與事件；核心規則依生產、品質與資訊流程運作。

本文件的數量代表已設計的關卡，實際可玩數目前為零。這是教材對照的遊戲規格，不代表官方試題、官方完整性認證或考試通過保證。實作可分批交付，完整驗收範圍仍是 108 關。

## 內容依據與狀態

- 教材主來源：[科目一](../科目一_生產與作業管理基礎/README.md)、[科目二](../科目二_智慧製造生產線管理基礎/README.md)及其十二份正文。

- APPX01–APPX03 以現有 Markdown 為來源。APPX04 的 topic 設定指向一個目前不存在的 Markdown；本設計引用實際存在的 [APPX04.ts](../../src/data/study-materials/APPX04.ts)。
- 正文、圖解 PNG、公式工具及題庫有不同用途。圖解是輔助材料，既有題庫是自編練習，遊戲關卡以本套來源對照與規則契約產生原創情境。
- 關卡資料、模擬引擎、遊戲畫面、離線續玩與學習成效均待後續實作及驗收。
