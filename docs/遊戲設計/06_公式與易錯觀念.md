## 二、共通數值與教學契約

1. 卡面必須同時提供量值、單位、資料期間與必要假設，例如「每件 30 秒」「每日需求」「本班負荷時間」。未知值顯示「資料不足」，不得當成 0。
2. 引擎以未四捨五入的數值計算；畫面一般顯示 2 位小數。人數、站數、件數、訂單數依情境取整，取整規則需在題幹與解析一致。
3. 比率內部統一使用小數，例如 15% 存為 0.15，畫面才乘 100。非有限值、單位混用、分母為 0 時不產生 NaN、Infinity 或綠色成功指標。
4. 無效資料應阻止提交該計算並提示缺少哪項條件；「產量 0」「故障 0」「平均偏移為負」有各自意義，不能一律套用「所有值必須大於 0」。
5. 每次行動顯示「改變了哪個輸入 → 影響哪項指標 → 造成什麼現場結果」，並提供前後值。正確計算只是一部分；前提、資料來源及措施效果也要成立。
6. 畫面中的快速演示時間與工廠模擬時間分開。加速播放不改變班次時長、到貨時點、加工速率或公式結果。
7. 本文件例子是實作時可使用的驗算基準；本次僅撰寫設計文件，尚未建置或執行遊戲測試。

## 三、七族公式與關卡整合

### F01：正常時間 NT 與標準工時 ST

**公式與單位**

- OT：觀測時間，秒／件或分鐘／件；r：評比係數，以小數表示；a：寬放率，以小數表示。
- `NT = OT × r`。
- 外加法，寬放以正常時間為基準：`ST = NT × (1 + a)`。
- 內含法，寬放佔標準工時的比例：`ST = NT ÷ (1 − a)`。

**前提／無效輸入**：OT、r 必須大於 0；a 不得為負，內含法須 a < 1。外加法在數學上不以 100% 為上限，教學可限定合理牌面範圍，但須明示。題目必須寫明寬放基準；未寫時顯示「需確認基準」，不能暗自預設。樣本代表正常作業，異常停機與返工須另分類，評比不是鼓勵加速動作或取消休息。

**數值例**：OT = 25 秒／件、r = 1.20、a = 0.15，NT = 30 秒／件；外加 ST = 34.50 秒／件，內含 ST = 35.29 秒／件。若 a = 0，兩式皆為 30 秒／件。

**整合**：C04 使用「確認觀測條件」「確認寬放基準」「更新標準作業」卡；C02、C12 用核准版次的 ST 計算負荷。動畫須呈現作業元素與必要寬放；驗收證據是基準選擇、計算軌跡與更新後工單負荷。

### F02：CT、TT、線平衡率 LE 與平衡損失率 BD

**公式與單位**

- tᵢ：工作站 i 完成一件所需時間；K：站數；T：同期間可用生產時間；D：同期間需求件數。
- 單一路徑、固定作業時間的串聯教學線：`CT = max(tᵢ)`；`TT = T ÷ D`。
- `LE = Σtᵢ ÷ (K × CT)`；`BD = 1 − LE`；畫面以百分比顯示。
- 穩態理論產能 `floor(T ÷ CT)`；此數值不直接等於空線起跑後的實際完工數。

**前提／無效輸入**：K 為正整數、每站工時 > 0、T > 0、D > 0，單位一致。D = 0 顯示「無需求，不需設定 TT」。工序移動受先行關係、設備、技能與品質檢查點限制；平行機、多品種換線、故障或有限緩衝時，不能直接用最大單站工時代表完整模型的實際 CT。

**數值例**：5 站為 18、24、30、22、26 秒／件，Σtᵢ = 120、CT = 30、LE = 80%、BD = 20%。T = 480 分鐘、D = 900 件，TT = 32 秒／件，穩態理論產能 960 件。若明定「空線開始、無故障、供料充足、無阻塞、逐件串聯」，首件需 120 秒，480 分鐘（T = 480 min × 60 = 28,800 s）完工數為 `1 + floor((28,800 − 120) ÷ 30) = 957`；畫面須選定並標出採用的起始條件。

**整合**：C04 的瓶頸救援先預測效果再打出「轉移可分割工序」「治具改善」卡；C01 比較需求與產能；C06 觀察等待及 WIP。把 18 秒站加快至 15 秒但瓶頸仍為 30 秒時，穩態產能不變，LE 可能下降；不得把 LE 單獨當成總體改善分數。

### F03：EOQ 與 EPQ

**公式與單位**

- D：年需求，件／年；S：每次訂購成本（EOQ）或每批設置成本（EPQ），元／次；H：單件年持有成本，元／件／年。
- `EOQ = √(2DS ÷ H)`；年訂購次數 `N = D ÷ EOQ`。
- d、p：同一時間單位的需求與生產速率，例如件／日；`EPQ = √(2DS ÷ [H × (1 − d/p)])`。
- EOQ 比較成本時用 `年訂購成本 = (D/Q) × S`、`平均循環庫存成本 = (Q/2) × H`；不含固定不變的購料成本與另設安全庫存成本。

**前提／無效輸入**：D、S、H > 0，EPQ 須 p > d > 0；D = 0 是不需補貨的情境，不硬算最佳批量。EOQ 教學模型假設需求穩定、整批到貨、無數量折扣、無缺貨；EPQ 改成邊生產邊消耗。產能、MOQ、保存期限、庫容若生效，須另外作可行性檢查，不能宣稱公式值必然可執行。

**數值例**：D = 10,000 件／年、S = 200 元／次、H = 4 元／件／年，EOQ = 1,000 件、N = 10 次／年。若每年 250 個工作日、d = 40、p = 80 件／日，EPQ = √2,000,000 ≈ 1,414.21 件。下單需整件時按題目規則比較相鄰整數或指定包裝倍數，不將 1,414.21 件直接發單。

**整合**：C03 使用「小批量多次訂購」「大批量訂購」「廠內分批生產」卡。資料面板同時畫訂購次數、庫存波形、持有成本與缺料；讓玩家說明採購一次到貨與製造逐步到貨的差異。C01、C12 只引用通過產能與物料條件的可行方案。

### F04：安全庫存 SS 與再訂購點 ROP

**公式與單位**

- 固定交期 L、每日需求獨立且波動模式穩定：`SS = Z × σd × √L`；`ROP = d̄ × L + SS`。
- d̄：件／日；σd：以一日為觀測期的需求標準差，件；L：天數；Z：無量綱常態分位數。
- 每日需求固定 d、交期波動：`SS = Z × d × σL`；`ROP = d × L̄ + SS`。L̄、σL 單位為天。

**前提／無效輸入**：Z ≥ 0、需求與標準差 ≥ 0、平均交期 > 0；本章教學服務水準採 ≥ 50% 的單尾週期服務水準，不與供貨件數達成率混用。σ = 0 得到 SS = 0 是有效結果。兩者同時變動、每日需求有強烈相關或需求趨勢改變時，這兩個簡式均不可直接套用。

**數值例**：d̄ = 50、σd = 6、L = 9、Z = 1.65，SS = 29.70 件、原始 ROP = 479.70 件。若政策為整件向上取整，SS = 30、ROP = 480 件。第二情境 d = 50、L̄ = 9、σL = 1、Z = 1.65，SS = 82.50、ROP = 532.50；按整件向上取整為 SS = 83、ROP = 533。

**整合**：C03 用「提前下單」「設定緩衝」「查核在途」卡；到貨倒數期間庫存繼續下降。教學最初無在途單、無欠交，才可直接看在手量觸發；有未結訂單時改看 `庫存位置 = 可用在手 + 已訂未到 − 欠交`，預留量與欠交不可重複扣除。C12 提供批號、隔離狀態與正確報工；安全庫存不能抵銷不正確的帳料資料。

### F05：整體設備效率 OEE

**公式與單位**

- L：計畫生產／負荷時間；R：其中實際運轉時間，兩者同單位；c：理想週期，時間／件；N：總完成件數；G：其中一次合格件數。
- `A = R/L`；`P = cN/R`；`Q = G/N`；`OEE = A × P × Q`。
- 同一範圍且資料有效時可用 `OEE = cG/L` 交叉核對。

**前提／無效輸入**：L > 0、0 ≤ R ≤ L、c > 0、N 與 G 為非負整數、G ≤ N。計畫不生產時間、換線與停機的歸屬在情境開始前公布；不能事後修改分母提高成績。若 P > 1，提示理想週期、計數或時間紀錄需查核，不直接截成 100%。若 R = 0 且 N = 0，A = 0，P／Q 顯示不適用，OEE 依 cG/L 為 0；L = 0 則整體不適用。R = 0 但 N > 0 是資料矛盾。

**數值例**：班次 480 分鐘，其中指定不生產 60，L = 420；負荷期間換模及卡料停機 42，R = 378；c = 0.5 分鐘／件、N = 600、G = 570。A = 90%、P = 79.37%、Q = 95%、OEE = 67.86%。教材中的 60 分鐘排除屬此例政策；不能推論所有「計畫保養」都永遠排除 OEE 分母。

**整合**：C06 選「減少換模」「排除瞬停」「防呆」卡，事件軸分別累計 A／P／Q 損失；C11 提供設備狀態、C12 提供班次及報工。故障與換模通常落在 A，瞬停及慢速在 P，開機與製程不良在 Q；短停門檻由情境政策固定，5 分鐘不是通用規範。同一事件不得同時從 R 扣除又列入 P 的失速時間。[Vorne OEE 六大損失說明](https://www.oee.com/oee-six-big-losses/)

### F06：MTBF、MTTR 與固有可用度

**公式與單位**

- U：可修復設備的有效運轉時間，時；V：相同統計範圍內維修時間，時；F：故障次數。
- `MTBF = U/F`；`MTTR = V/F`；單位時／次。
- `Ai = MTBF ÷ (MTBF + MTTR)`，為無量綱比率。

**前提／無效輸入**：F 為正整數時才可用上述樣本平均式；U > 0、V ≥ 0。F = 0 顯示「期間無觀測故障，無法由此樣本估計 MTBF」，不得寫成無限可靠或頒發 100% 永久可用勳章。V 的紀錄需明定是否僅維修活動，不能把等待備料、計畫保養、無需求停機混入後仍稱固有可用度。MTTR 的統計事件範圍須與故障事件相符，未完成維修不能當成 0 小時結案。

**數值例**：U = 600 小時、F = 4、V = 2 + 1.5 + 3.5 + 1 = 8 小時；MTBF = 150 小時／次、MTTR = 2 小時／次、Ai = 150/152 = 98.68%。此 Ai 不等於 F05 的班次 OEE 或其可動率，兩者時間邊界與損失範圍不同。

**整合**：C06、C11 用「預防原因再發」「改善維修步驟」「確認備料」卡分辨降低故障頻率與縮短復原時間；C09 接預測性維護。驗收看事件歷程與處置效果，不能憑刪除故障紀錄使 MTBF 上升。

### F07：Ca、Cp 與 Cpk

**公式與單位**

- USL、LSL、x̄、σ 必須是同一量測單位；規格中心 m = (USL + LSL)/2，規格寬 W = USL − LSL。
- 本教材採帶方向的偏移比率 `ca = (x̄ − m)/(W/2)`；畫面 `Ca = ca × 100%`。
- `Cp = W/(6σ)`。
- `Cpk = min((USL − x̄)/(3σ), (x̄ − LSL)/(3σ)) = (1 − abs(ca)) × Cp`。
- Ca 是百分比呈現，Cp、Cpk 無單位；代入 Cpk 的必須是小數 ca，不能直接代入畫面的 16.67。

**前提／無效輸入**：USL > LSL、σ > 0；x̄ 可以是負數，也可以落在規格之外，後者可得到負的 Cpk，需正確呈現。σ = 0 不回傳無限能力。教材本關採雙邊規格、合理穩定且近似常態的教學資料；應先確認量測資料及製程穩定性，再解讀能力，不將管制界限當成規格。[NIST 製程能力說明](https://www.itl.nist.gov/div898/handbook/pmc/section1/pmc16.htm)

**數值例**：USL = 50.06、LSL = 49.94、x̄ = 50.01、σ = 0.01 mm；m = 50.00、W = 0.12，ca = 1/6、Ca = 16.67%、Cp = 2.00、Cpk = 1.67。若只把 x̄ 調回 50.00，Cp 仍為 2.00，Ca = 0%、Cpk = 2.00；若只降低 σ，才會縮小散布。

**整合**：C05 使用「檢查量測」「查特殊原因」「調整中心」「降低變異」卡。動畫畫出分布、中心線及固定規格；C09 的 AOI 合格判定與 C12 的品質閘門可引用結果，但不能只因 Cpk 高就忽略失控訊號或個別不良品。

| :--- | :--- | :--- | :--- |
| E01／C06、C03 | 每台設備一直生產就最有效率；不良是任何情境下唯一最嚴重浪費 | 過量生產會帶出庫存、搬運、等待與問題隱藏。辨認 TPS 對過量生產的重視，同時按實際交期、品質與需求判斷現場優先順序 | 出「依消耗拉動」後，在需求不變下 WIP、庫位佔用下降；復盤指出多製品未增加客戶交付 |

| E03／C05 | 不良品數與缺點數混用；固定 n 就不能用 p 圖 | p 看不良率，n 可固定或變動；np 看不良品數，教學採固定 n；c 看固定檢驗機會的缺點數；u 看單位平均缺點數，適用機會數不同情境。題目若 n 固定，須以「要看件數或比例」消除 p／np 多解 | 卡面帶「件／缺點／面積」及樣本量；相同 5 個不良、n 由 100 變 200 時不良率從 5% 變 2.5%；一件兩處缺點只算一件不良 |
| E04／C08、C11 | 把 Input Register 當可寫設定值；把 40001 原樣當封包位址 | Discrete Input 為唯讀 1 bit；Coil 可讀寫 1 bit；Input Register 唯讀 16 bit；Holding Register 可讀寫 16 bit。需依設備對照表辨認功能碼與位址基準；4xxxx 是常見文件表示法 | 「讀取實測溫度」與「寫入核准目標值」走不同資料格；對唯讀區寫入會被拒絕，資料不變，顯示原因；正常 Modbus 不充當安全互鎖 |
| E05／C10、C07 | 只要有 3D 模型就是數位雙生；所有數位雙生都必須無人核准自動控制 | 本關區分靜態模型、單向同步監測與有模型分析／驗證／回饋的虛實應用。數位雙生定義有不同框架，不能以全自動反寫作通用唯一條件；本關的閉迴路是特定操作目標 | 先連資料同步、驗證模型，再以「核准部署」卡傳回受限設定；畫面呈現資料時間、預測誤差與回饋箭頭。保留人工核准仍可完成此關 |
| E06／C11 | 所有 AGV 都是磁條車；AMR 可穿越任何障礙 | 教學明定比較「固定導引路徑車」與「能在已建圖可通行空間重新規劃的 AMR」。按指定設備能力選擇；SLAM 不代表任何場景都能繞過，也不取代停障保護 | 同一路障下，固定路徑車安全等待；AMR 有合法替代路徑時改道，無路時也停止。驗收包含載重、通道與禁入區 |
| E07／C09、C05 | FN／FP 對反；準確率高就不會漏檢；提高過檢可無限降低風險 | 以「瑕疵」為正類：FN 為瑕疵被放行、FP 為良品被攔截。門檻依題定漏檢上限、複判量能與成本選擇；不能假設全產業都有同一絕對門檻。高風險情境可明定零已知瑕疵放行條件 | 打出門檻與「人工複判」卡後，混淆矩陣、漏出件數、複判佇列同時更新；保留相同批次真實標籤比較方案，避免只獎勵高準確率 |
| E08／C02、C03 | EBOM 與 MBOM 可直接互換；任何特定料必定只存在其中一種 | EBOM 表達設計結構；MBOM 依實際製造含用料、耗損、包裝、製程等資訊。膠水、虛擬件是否在哪種 BOM 出現，取決於企業資料規則，不能只憑名稱判斷 | 題目提供受控 EBOM 與製造需求卡；補入已指定耗材、用量與版次後，齊套檢查通過，不能靠略過缺料或版本差異過關 |
| E09／C04 | 寬放 20% 永遠乘 1.2；未註明就猜外加 | 外加基準為 NT，內含基準為 ST；未提供基準應要求條件補足。本設計不將教材中的預設口訣當成通用判分規則 | 同一 NT = 30 秒，選「佔 NT 的 20%」得到 36 秒，選「佔 ST 的 20%」得到 37.5 秒；時間帶標出各自分母 |
| E10／C01、C12 | SPT 永遠最少 WIP、EDD 永遠解決所有逾期、CR < 1 就保證最優 | 基礎題明定單機、作業同時到達、不可搶佔、無額外先行或換線約束：SPT 最小化平均流程時間，EDD 最小化最大 lateness。CR = (交期 − 現在)/剩餘加工時間，較小值通常較急，是派工啟發式；分母須 > 0，逾期可為負值 | 固定訂單打出 SPT／EDD／CR 卡，甘特圖並列完工時間、平均流程時間、最大 lateness；加入急單後重新計算，不將任何牌判為所有指標都最佳 |

### 來源差異與判分優先順序

本設計保留原教材，並在規格內明列下列校正；實作不能從教材摘要自動產生未經審閱的正解。發生衝突時，採「情境明示條件 → 本文件公式及觀念規格 → 章節教材的條件化解釋」。

- E03：NIST 的 p 圖範例本身即採固定樣本量，因此「固定 n 必須選 np」缺少衡量目標條件。[NIST：Proportions Control Charts](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc332.htm)
- E04：四種資料區、位元寬度及存取功能依 Modbus 組織規格；具體設備位址需查其映射。[Modbus Application Protocol V1.1b3](https://www.modbus.org/file/secure/modbusprotocolspecification.pdf)
- E05：NIST 概述數位雙生可用於監測、預測、最佳化與決策支持；本案據此不將「自主反寫控制器」設為通用必要條件。[NIST：Digital Twins](https://www.nist.gov/digital-twins)
- E06：自動避障與動態路徑是設備能力，需連同現場條件檢查。本關使用明示能力的教學車型，並參考製造商對 AMR 的自動繞行說明。[OMRON：Mobile Robot Navigation](https://automation.omron.com/en/mx/blog/key-considerations-selecting-mobile-robot-vendor)
- E07：沿用 C09 現有教材「混淆矩陣與門檻選擇」的風險與複判成本取捨，避免把 APPX02 的「絕對不允許升高」寫成所有關卡唯一規則。[AI 與機器視覺檢測教材](../科目二_智慧製造生產線管理基礎/03_人工智慧AI與機器視覺檢測.md)
- E08／E09：採本題已給定的 BOM 管理規則與寬放定義；不得依未確認的企業慣例或檢定預設補出正解。
- E10：SPT、EDD 的結果限定在基本單機模型。將多機、到達時間、權重或換線加入後需重新求解，不能沿用無條件最優的文案。[Georgia Tech：Single-machine Scheduling 課程解答](https://www2.isye.gatech.edu/~spyros/courses/IE4803/Fall-19/Final-Sol.pdf)

## 六、APPX04 複習方法與學習證據

APPX04 的「先章節、再 CBT、錯題回到決策或資料流」轉為每關固定復盤：

1. **找問題**：讓玩家從交期、庫存、品質、設備、資料整合選出此關主要目標；同時保留其他不得破壞的條件。
2. **認層級**：以卡牌標籤辨認企業規劃、製造執行、設備控制、感測資料；回放行動實際改變哪一層。
3. **核效果**：比較改善前後現場證據，不能因選了 MES、AI、看板等工具名就獲得成功。
4. **驗條件**：展示題目已給數值、使用公式與前提；資料不足時給「補資料」卡，不要求玩家猜未提供的數值。

每筆規劃中的學習紀錄包含：關卡 ID、章節代碼、F／E 標籤、情境版本、固定牌組版本、提交卡序、前後指標、理由選擇、提示使用與重試次數。它是遊戲理解紀錄，不直接改寫現有 CBT 考試分數或把玩過視為精熟。

「理解」至少須同時有正確決策、可對應畫面的理由，以及不同數值或資料條件下仍能完成的遷移證據。先沿 108 關中的既有章節與整合關安排遷移檢查；同關換固定情境版本仍屬重玩，不額外增加關卡數。

錯誤導引例：E09 錯 → C04／F01／APPX01；E03 錯 → C05／APPX02；E04 錯 → C08／APPX02；E05 錯 → C10／來源差異說明；跨層責任錯 → C07、C12／APPX04。玩家可自由回章節閱讀，取得提示後仍可重玩並清楚保留提示紀錄。
