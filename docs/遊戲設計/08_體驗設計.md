# 體驗設計

狀態：設計規格。本文件補充 [01_遊戲架構](01_遊戲架構.md) 未涵蓋的玩家情感體驗、節奏、回饋與無障礙設計。

## 1. 敘事框架

玩家扮演一位剛到職的「新人智慧生產工程師」，從接手單一機台的異常開始，逐步成長為能統籌整廠數位轉型的主管。
- **十二部門的場景敘事與角色互動**：每個章節（C01–C12）對應一個特定部門。例如在 C01（營運指揮室），玩家會與生管前輩對話，前輩會抱怨急單插單的問題；在 C09（AI 檢測站），玩家會與品管同仁合作處理誤判率。NPC 不只給任務，也會在檢核時給予專業回饋。
- **導入→章節→綜合的敘事節奏**：T01–T04 為「入職培訓」，提供高度容錯的安全環境。C01–C12 為「日常挑戰」，各部門獨立運作。X01–X08 為「高層專案」，玩家必須協調多部門資源（例如 X01 的新產品試產專案）。
- **文字風格指引**：文字必須簡潔、專業、不說教。不使用「你應該知道」這類說教語氣。對話氣泡不超過三行。錯誤提示應為「機台設定參數超出公差範圍（上限：2.5mm），導致不良率上升」，而非「你設錯了，回去重看講義」。

## 2. 回饋設計

所有回饋依循「桌面/手機佈局」的四大區塊進行視覺化。
- **卡牌打出的視覺與音效回饋**：當玩家從「手牌／參數」區拖曳或點選卡牌（如：F02 途程卡）至「場景／證據」區時，會有清脆的「卡扣」音效（Snap），並顯示消耗的改善預算。若操作受限，卡牌會以紅色邊框抖動退回，並伴隨低沉的提示音。
- **KPI 達標／未達標的動態效果**：在「基準／本次」面板，產出或品質達標時，數值會以綠色閃爍放大後定格，並有上升箭頭。未達標或超支時，則以橙色顯示（避免全紅造成的挫折感）。
- **模擬播放中的狀態提示**：工件移動使用 SVG 路徑動畫。正常狀態為藍色；排隊等待為黃色漏斗圖示；設備故障為紅色閃爍的扳手圖示。動畫加速時，不改變事件先後順序，僅加快視覺位移。
- **錯誤操作的非懲罰性回饋**：給出無效指令（如：未完成首件檢查就釋放量產），系統不會扣除預算，而是暫停時間軸，彈出「互鎖提示：缺少首件核准，產線無法啟動」，引導玩家出對應卡牌。

## 3. 節奏與認知負荷管理

為避免玩家在學習製造概念時過度疲勞，引入 Cognitive Load Index (CLI)。
- **CLI (Cognitive Load Index) 1–5 級定義與計算**：
  CLI = (初始變數數量 × 0.5) + (可選卡牌種類 × 1) + (需計算的公式數量 × 2)
  - 級別 1 (CLI < 3)：單一因果（例如 T01）。
  - 級別 2 (CLI 3-4)：簡單決策。
  - 級別 3 (CLI 5-8)：多變數權衡（例如 C04 算線平衡，變數多且需計算）。
  - 級別 4 (CLI 9-11)：複雜系統問題。
  - 級別 5 (CLI ≥ 12)：全廠資源調度（例如 X08）。
- **章內八關的難度曲線設計原則**：每章 L01–L08 的 CLI 預計從 2 逐步上升至 4。L01 為基本概念操作，L04 為數值計算，L08 為複雜情境排除。
- **休息點、成就回顧與學習摘要插入時機**：每完成一個章節的 L08 關卡，系統會播放短暫的「部門認可」過場，並在「事件／解析」側欄插入該章節的學習摘要與成就回顧。
- **長關卡（X08）的分段保存與恢復體驗**：X08 綜合挑戰預估遊玩時間超過 20 分鐘，必須支援階段性自動存檔。玩家重啟時，從上一個達成的里程碑（如：完成物料齊套檢查）繼續。

## 4. 成就與進度視覺化

- **星等與通關率的呈現方式**：在關卡選擇選單，各關以 1-3 顆星星標示狀態（一星理解、二星改善、三星遷移）。總通關率（完成的 levelId 數 / 108）以環形進度條顯示在主頁面頂部。
- **概念掌握度的視覺化**：採用「智慧生產能力雷達圖」（六大維度對應）。每個 conceptId 取得證據後，會點亮雷達圖上的對應節點；也有展開的能力樹檢視詳細知識點。
- **徽章系統設計**：分為「里程碑徽章」（如：完成所有 T 系列關卡獲得「報到首日」）與「特殊成就徽章」（如：在 C06 中以最少預算將 OEE 提升至 85% 獲得「精實大師」）。
- **可分享的成績卡設計**：完成特定 X 系列關卡後，提供一張可匯出的成績卡圖片，包含玩家 ID、雷達圖、獲得的稀有徽章，供社群分享。

## 5. 無障礙設計

所有介面操作都需滿足基本無障礙要求。
- **鍵盤操作與螢幕閱讀器支援規格**：遊戲支援 Tab 鍵焦點切換與 Enter 鍵確認。「事件／解析」側欄的文字需能被 NVDA 或 VoiceOver 讀取。狀態變化需附帶 aria-live 宣告。
- **色彩對比與色盲友善配色**：紅綠狀態指示必須同時搭配形狀差異（圓形打勾與三角形驚嘆號）。色彩對比度符合 WCAG 2.1 AA 標準（文字對比至少 4.5:1）。
- **字級調整與減少動態模式**：提供全域設定，允許玩家放大介面文字。提供「減少動態」模式，關閉背景粒子效果與視角縮放，將動畫簡化為狀態切換。
- **觸控與滑鼠的操作等價**：拖曳卡牌為預設，但點選卡牌後再點擊目標區域的「點擊-點擊」操作模式必須等效支援，方便不便精細拖曳的玩家及手機觸控用戶。

## 6. 首次使用者體驗（FTUE）

- **開場流程設計**：玩家首次進入遊戲時，只會看到一張簡單的員工識別證，輸入名稱後，畫面切換至工廠大門，隨即收到第一條任務簡訊，自然引導至 T01。
- **漸進式功能解鎖**：一開始只開放「場景／證據」與「手牌／參數」區。KPI 面板、時間加速功能與「事件／解析」側欄會在 T02–T04 中隨著任務需要逐步解鎖，避免一開始資訊過載。
- **T01–T04 的引導 UX 設計**：採用「聚光燈」效果，調暗非活動區域，高亮需要玩家操作的第一張卡牌。操作後立即顯示因果關係，確保玩家建立「出牌 → 看結果 → 找原因」的心智模型。

## 7. 情境音樂與音效設計指引

- **五種場景引擎的音樂風格**：
  1. 生產與物流：穩定的 4/4 拍中速電子樂，帶有機械律動感。
  2. 計畫與文件：安靜、專注的環境音（Ambient），如輕微的鍵盤聲或低頻合成器。
  3. 診斷與品質：帶有懸疑感的微小音效，突顯尋找根因的專注。
  4. 資料與架構：充滿科技感的數位琶音，如同數據流動。
  5. 控制與驗證：具備未來感的合成波（Synthwave），強調虛實整合。
- **關鍵事件音效清單**：
  - 錯誤／無效操作：短促的低頻「啵」聲（不刺耳）。
  - 任務一星通關：清脆的銅管和弦。
  - 發現品質異常：明顯但不驚悚的警示聲（如兩下清脆的敲擊）。
- **音量控制與靜音支援**：BGM 與 SFX 分開控制，預設音量為 50%。支援全域一鍵靜音，且系統自動記錄玩家的音量設定供下次遊玩使用。
