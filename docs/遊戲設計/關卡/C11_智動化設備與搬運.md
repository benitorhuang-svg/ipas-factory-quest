# C11 智動化設備與搬運：讓機器在規則內動作

> 狀態：遊戲設計規格，尚未實作。8 關；每關約 8–12 分鐘。

教材來源：[智動化生產設備與傳送系統](../../科目二_智慧製造生產線管理基礎/05_智動化生產設備與傳送系統.md)、[APPX02 陷阱 6](../../歷屆試題與解題技巧/考古題盲點與常見陷阱.md)。對應 T2.3／P2.3.1 與 M12202 核心清單。

章節先修：C10 的實體模型與控制；章內 L01 → L08。

2D 場景顯示感測器 → PLC／控制器 → 執行機構與搬運設備，均可暫停、單步與比較回放；教學沒有操作倒數，提供固定可解牌組。

卡牌共同契約：每關配置點獨立。先選目標設備、確認負載與安全規範才能配置；不符前置時不扣點並指出安全或規格衝突。成功部署能確保設備合規且穩定運行，並消除搬運瓶頸。

基本通關需達成操作目標與原因辨識；效率條件給第二星，換情境遷移題給第三星，使用提示不阻擋基本通關。所有數字是本關情境參數，不當作設備的普遍效能承諾。

## C11-L01 掃描週期的時序錯覺

1. **核心概念**：PLC 掃描週期、輸入映像、程式掃描與輸出更新、訊號鎖存。

2. **初始情境／數據**：包裝站 PLC 掃描週期 20 ms；光電感測工件經過，短暫遮蔽僅 10 ms。系統漏抓工件。

3. **可用卡牌與限制**：「調整掃描週期」1 點、「中斷常式」1 點、「硬體鎖存輸入」1 點，預算 2；卡牌家族 F15。不能隨意縮短週期導致控制器超載。

4. **操作與可見因果**：慢速播放三部曲動畫。若未調整，10 ms 訊號在「程式執行」前消失；加入硬體鎖存後，輸入映像正確保持訊號至下一個掃描週期。

5. **通關／失敗**：連續 5 工件正確計數並驅動推桿；原因選「輸入訊號長度必須大於掃描週期或使用鎖存」。遷移題換成 5 ms 彈跳干擾需濾波延遲；盲目降週期至 1 ms 導致運作當機即失敗。

6. **變化挑戰／誤區**：增加通訊負載使掃描週期浮動；誤以為 PLC 的任何瞬間都能即時反應所有外部變化。

## C11-L02 梯形圖邏輯與控制

1. **核心概念**：梯形圖 (LD)、自保持邏輯、分散式 I/O、互鎖。

2. **初始情境／數據**：兩條輸送帶交匯，有啟動與停止按鈕。原有集中 PLC 線路過長，訊號延遲 100 ms 且放開啟動按鈕馬達就停。

3. **可用卡牌與限制**：「分散式 I/O」1 點、「自保持電路」1 點、「防撞互鎖」1 點，預算 2。F15 設備卡。

4. **操作與可見因果**：更換分散式 I/O 降延遲至 15 ms；梯形圖中並聯馬達輸出至啟動按鈕下形成自保持，並串聯互鎖接點。動畫顯示電流路徑。

5. **通關／失敗**：按下按鈕後馬達持續運轉，且兩帶交匯無碰撞；原因選「利用自保持邏輯維持狀態與互鎖防撞」。遷移題改用 FBD 進行溫度設定；未加自保持導致停止訊號失效即失敗。

6. **變化挑戰／誤區**：加入通訊斷線模擬；誤以為 DCS 只是把 PLC 放遠，忽略了分散式控制需要處理通訊狀態。

## C11-L03 適合的機械手臂

1. **核心概念**：工業機器人構型選型、世界坐標系、工具中心點 (TCP)。

2. **初始情境／數據**：三個工作站：(A) PCB 高速插件；(B) 汽車鈑金焊接；(C) 實驗室試管取放。均無護欄且人員頻繁進出。

3. **可用卡牌與限制**：「SCARA 機器人」1 點、「六軸機器人」1 點、「協作型機器人 (Cobot)」1 點、「TCP 校正」1 點，預算 4。需滿足速度與安全。

4. **操作與可見因果**：配對機器人，顯示工作範圍與安全護欄需求；C 站換夾爪後，未校正 TCP 導致軌跡偏移 20 mm 撞破試管，打出 TCP 校正卡修正。

5. **通關／失敗**：A 用 SCARA、B 用六軸加護欄、C 用 Cobot 且全數校正 TCP，無碰撞完工；原因選「依運動特徵選型且更換工具必重校 TCP」。遷移題將 Delta 用於食品高速分揀；未加護欄的六軸直接運轉即失敗。

6. **變化挑戰／誤區**：增加夾具重量超過 Cobot 負載上限；誤以為協作型機器人絕對安全而免除風險評估。

## C11-L04 安全互鎖與受控復歸

1. **核心概念**：安全互鎖 (Interlock)、急停、故障復歸、非預期啟動。

2. **初始情境／數據**：一台沖床卡料，操作員開門排除。軟體顯示停止，但關門瞬間機台自動啟動，造成潛在夾傷。

3. **可用卡牌與限制**：「硬體安全門互鎖」1 點、「獨立復歸按鈕」1 點、「軟體旗標」1 點，預算 2。F15 設備卡，無法單靠軟體解決。

4. **操作與可見因果**：部署安全門互鎖與獨立復歸。開門時實體切斷動力；關門後，PLC 雖有啟動訊號，但需人工在安全區外按下復歸鈕才會供電。

5. **通關／失敗**：完成 3 次卡料排除，人員在危險區時無法復電，關門並按復歸後才啟動；原因選「故障排除與重新啟動必須是獨立且受控的行為」。遷移題為網路恢復後的狀態判定；僅靠軟體旗標當作安全防護即失敗。

6. **變化挑戰／誤區**：維修需通電寸動點檢；誤以為 PLC 程式裡寫了停止就等於機台處於安全斷電狀態。

## C11-L05 倉儲與固定搬運

1. **核心概念**：自動倉儲 (ASRS)、輸送帶 (Conveyor) 吞吐量、物料分流。

2. **初始情境／數據**：物流中心需儲存 5000 托盤，每小時需分流 300 托盤至 4 個出貨口。目前平放地面且用無人堆高機，空間不足且塞車。

3. **可用卡牌與限制**：「ASRS 立體庫」2 點、「滾筒輸送帶」1 點、「分揀道岔」1 點，預算 4。受限於場地高度與承重。

4. **操作與可見因果**：建置 ASRS 釋放平面空間，連結輸送帶與分流道岔。托盤自動入出庫，依條碼在道岔處分流，消除等待浪費。

5. **通關／失敗**：空間利用率達標且每小時連續出貨達 300 托盤無阻塞；原因選「高密度儲存與固定高流量應選用 ASRS 與輸送帶」。遷移題為增加出貨口需調整道岔時序；用堆高機硬扛 300 托盤導致碰撞即失敗。

6. **變化挑戰／誤區**：輸送帶馬達故障導致整線停擺；認為所有搬運都能用單一移動載具解決，忽略 ASRS 的前置成本與空間優勢。

## C11-L06 軌道導引還是自主移動

1. **核心概念**：AGV 與 AMR 的導航技術、避障行為、路徑彈性。

2. **初始情境／數據**：兩條路線：(A) 產線間固定單純直線；(B) 人機混流且常有物料擋道的加工區。均配發磁條 AGV。

3. **可用卡牌與限制**：「維持磁條 AGV」1 點、「SLAM 導航 AMR」1 點、「清除路障」1 點，預算 2。F15 搬運卡。

4. **操作與可見因果**：路線 A 的 AGV 正常運作；路線 B 的 AGV 遇障礙即停等。換上 AMR 後，遇障礙能利用光達即時計算新路徑繞行抵達終點。

5. **通關／失敗**：A 站維持 AGV，B 站換成 AMR，連續 5 次任務均在時限內完成；原因選「AGV 遇障停等，AMR 具備動態繞障能力」。遷移題在狹窄單行道放 AMR，無法繞行時仍需安全停等；認為 AMR 絕對不會塞車或能穿越實體障礙即失敗。

6. **變化挑戰／誤區**：障礙物過大封死通道導致 AMR 亦無法繞過；誤以為 AMR 不需要任何交管，或以為所有無人車都是沿線走的 AGV。

## C11-L07 死鎖與區域占用

1. **核心概念**：車隊調度管理 (FMS)、交通管制、死鎖 (Deadlock) 預防、路權。

2. **初始情境／數據**：5 台無人車在有 2 條單行巷道與十字路口的車間運行。頻繁發生兩車在巷道對頭相遇，互相等待造成死鎖。

3. **可用卡牌與限制**：「區域路權互鎖 (Zone Control)」1 點、「單行道規劃」1 點、「電量管理」1 點，預算 2。F15 任務卡。

4. **操作與可見因果**：部署路權控制，車輛進入巷道前向 FMS 申請，系統鎖定該區間（顯示紅區），其他車輛需在入口等待綠燈。

5. **通關／失敗**：1 小時模擬中無死鎖發生，總搬運量達 50 趟；原因選「透過路權與交管系統防止多車爭用同一資源」。遷移題加入低電量 AMR 需優先借道回充；僅靠車載防撞而無上位調度導致全場卡死即失敗。

6. **變化挑戰／誤區**：通訊延遲導致路權釋放不及時；誤以為設備有自主導航就完全不需要上位系統的交通管制。

## C11-L08 狀態機與預防保養

1. **核心概念**：設備狀態機、預防保養、消耗品點檢、故障預警。

2. **初始情境／數據**：CNC 機台頻繁無預警當機。狀態紀錄只有「運轉」與「停機」；切削液 30 天未換導致過熱，無人點檢。

3. **可用卡牌與限制**：「細化設備狀態」1 點、「自主保養表」1 點、「更換耗材」1 點，預算 3。F09 維護與 F15 設備卡。

4. **操作與可見因果**：導入細化狀態 (如 Held, Aborted)，顯示機台實時異常類別。套用自主保養表後，操作員依燈號確認液位，異常即轉為暫停 (Held) 待修並發出工單。

5. **通關／失敗**：連續 60 天無災難性當機，歷程清晰區分待料、保養與故障；原因選「明確設備狀態機與落實定期點檢能早期預警」。遷移題為主軸震動變大，需提早排定保養；忽略告警強制運轉直到報廢即失敗。

6. **變化挑戰／誤區**：保養時間壓縮了短期可生產時間；誤將所有停機歸咎於操作不當，忽略了明確的點檢標準與狀態追蹤。
