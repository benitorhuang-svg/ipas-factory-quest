# 練習題解析調整

2026-11-05。範圍為單元練習、錯題複習與模擬考交卷後的逐題解析；公告試題閱讀頁維持既有教材解析流程。

## 重複原因與顯示規則

舊 renderer 只收集帶有「正解」標記的本文。當原始解析是「未標記本文＋【重點辨析】」時，將整份文字回退作為正解，再重繪辨析區，導致辨析出現兩次；「破題關鍵」雖在已知標記中，卻沒有實際對應區段。

新分段器保留標記前的本文、收集所有已知區段、合併重複區段並去除相同段落；未知標記仍留在本文，不靜默刪除。所有文字皆以 HTML escape 顯示。

- 破題關鍵：先辨認統計口徑、題目條件或所求量。
- 正解解析／解題步驟：將判讀或計算依序展開，多步驟使用編號列表。
- 選項辨析：逐一說明錯誤選項與題設的差異，隨本次作答的選項順序顯示字母，並標出實際錯選。
- 結果檢核與遷移：用反算、單位、數量界限或適用條件檢查答案。

全部題目均有逐題編寫的理由與檢核，不以「其他選項均為干擾項」等空泛文字充數。提示若已完整出現在正解本文中，不再重複顯示。

## 維護與驗證

解析資料以 Engine 的題目內容指紋綁定單元、題幹、種類、選項順序、答案、容差與單位。變更上述內容後，必須重新核對解析及選項理由；不可只更新雜湊跳過核對。

新增的按單元資料每筆採六欄：`[原選項0理由, 原選項1理由, 原選項2理由, 原選項3理由, 檢核與延伸, 內容指紋]`。建置時以現有實質解釋為第一步、正確選項的補充理由為第二步；提示與正解重複時不重繪。理由在顯示時依本次作答順序映射，不在內容中硬編選項字母。

建置逐題確認解析存在、四個選項都有不同且非空泛的理由、步驟與檢核齊備、內容指紋有效；任何一道唯一題缺失即停止，不能回退舊短解析充作完成。

解析與應用模組建入 data.js 與 app-bundle.js，使用現有外殼快取，不增加作答結果的網路依賴。

進度、作答與報告記錄 questionRevision，避免匯入或重載時重複遷移。無版本的正式版存檔視為原版試卷；原報告保留當時題幹、選項及字母。原版試卷使用原解析，新開試卷採本次完整深化解析。tests/question-versions.mjs 對全部 476 題確認草稿、歷史正確性與新版隔離，另有真實瀏覽器的舊卷恢復與交卷驗證。

`tests/explanations.mjs` 檢查 416 題覆蓋與完整 396 題候選池、400 次兩科標準／高難抽題、全部 24 種選項排列、錯選標示、HTML escape、別名一致性、修正題回歸與舊分數重算、已發布資料一致性、缺題與指紋過期時拒絕建置。

瀏覽器測試涵蓋 390／1440px、交卷、重載、file URL 與 Chromium 原生離線，另實際完成兩科×兩模式各 50 題模擬，逐張結果卡核對步驟、三個錯誤選項理由、錯選字母及檢核內容。
