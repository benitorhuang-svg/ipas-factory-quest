## 審查準則與實際修正

- 題幹提供能支持唯一正解的條件；反向題、分類與公式先說清楚採用的口徑。
- 正解說明包含概念、題目應用或明示的例子，避免把同一定義改寫兩次充當推理。
- 每道單選題四個選項都有對應理由；交卷顯示三個錯誤選項，理由隨實際選項意義及洗牌字母對應。
- 計算題核對分子、分母、單位、時點、百分比與取位方式，不捏造未提供的損失或供給。
- 檢核只服務本題能力；章節相關但與判斷無關的提醒不再混入。
- 舉例的額外數字以「例如」等語明示，不當成原題提供的條件。

## 驗證紀錄

發布前執行零警告 lint、完整 build／資料與引擎測試，以及 Chromium／WebKit 瀏覽器套件。新增驗證包含：416 份審查紀錄與來源一致、歷史選項理由重排、ISA-95 具體推理與來源、396 題池全部解析在手機及桌面寬度實際渲染、重新載入後保留。瀏覽器抽題與離線測試另驗證標準／高難、兩科各 50 題，不能以它取代整題池審查。

本機最終結果：lint 零警告、完整 build 與 npm test 通過；Chromium／WebKit 全套 **57 通過、5 跳過、0 失敗**。跳過項為 WebKit 的 CDP 節流及此套件的原生 Service Worker 測試限制；相應案例在 Chromium 通過。396 題池在兩瀏覽器、兩個寬度的四項檢查全部通過。原始整合來源 891 份雜湊保持一致。
